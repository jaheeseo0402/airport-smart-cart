# 핀 연결표 (아두이노 우노, 최종 코드 기준)

`+ 레일` = 아두이노 5V (센서 6개 전용, 모터 드라이버 VCC는 연결 금지)
`− 레일` = 공통 GND (아두이노, 모터 배터리 −, 모터 드라이버, 센서 전부)

| 부품 | 부품 핀 | 연결할 곳 |
|---|---|---|
| 아두이노 | 5V | + 레일 |
| | GND | − 레일 |
| | USB | 라즈베리파이 USB (전원 + 시리얼 9600) |
| 모터 배터리 | + | 모터 드라이버 VCC |
| | − | 모터 드라이버 GND, − 레일 |
| 모터 드라이버 | VCC | 모터 배터리 + |
| | GND | 모터 배터리 −, − 레일 |
| | A-1A / A-2A | 아두이노 5 / 6 (출력 A → 오른쪽 모터) |
| | B-1A / B-2A | 아두이노 9 / 10 (출력 B → 왼쪽 모터) |
| 라인센서 왼쪽 | VCC / GND / OUT | + 레일 / − 레일 / 아두이노 2 |
| 라인센서 오른쪽 | VCC / GND / OUT | + 레일 / − 레일 / 아두이노 3 |
| 초음파 앞 | VCC / GND / TRIG / ECHO | + 레일 / − 레일 / 7 / 8 |
| 초음파 왼쪽 | VCC / GND / TRIG / ECHO | + 레일 / − 레일 / 11 / 12 |
| 초음파 오른쪽 | VCC / GND / TRIG / ECHO | + 레일 / − 레일 / A0 / A1 |
| 초음파 뒤 | VCC / GND / TRIG / ECHO | + 레일 / − 레일 / A2 / A3 |

- 라인센서의 EN 핀은 모듈의 점퍼를 그대로 둡니다.
- 비어 있는 핀: 4, 13 (0, 1은 USB 통신용이라 사용하지 않음)
- 모터를 연결해 보니 바퀴가 뒤로 돌고 좌우가 바뀌어서, **배선은 위 표 그대로 두고 코드에서** 왼쪽 바퀴를 10/9번, 오른쪽 바퀴를 6/5번으로 지정했습니다.
